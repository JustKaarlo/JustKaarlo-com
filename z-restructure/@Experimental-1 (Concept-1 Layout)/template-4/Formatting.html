00 System Overview

The doc system consists of four files that work together:

FilePurpose
doc-data.jsAll article content + DocRegistry map
doc-system.jsEngine — renders cards, opens modals, TOC, deep links
index.cssAll styling including every formatting component
page-template.htmlPage shell — copy once per game/section, change 6 vars
Info

Formatting components like callouts, code blocks, tabs etc. are placed inside the description field of your article objects in doc-data.js. They are plain HTML strings rendered into the modal.

01 Adding Pages & Articles

To add a new game / section page:

doc-data.js
// 1. Add your article array const myGameArticles = [ { title: 'Getting Started', subtitle: 'First steps guide', icon: 'https://...icon.png', contentType: 'description', description: `<p>Hello world!</p>` }, // Section divider: { type: 'section', title: 'Advanced' }, { title: 'Tips & Tricks', subtitle: 'Pro moves', icon: 'https://...icon.png', contentType: 'link', link: 'https://...' } ]; // 2. Register in DocRegistry const DocRegistry = { menu: menu, mygame: myGameArticles, // ← add this get(pageId) { return this[pageId] || []; } };
page-template.html — 6 vars to change
const PAGE = { id: 'mygame', title: 'MY GAME TITLE', subtitle: 'GUIDES & TIPS', logoSrc: 'https://...logo.png', bgImage: 'https://...bg.jpg', accentColor: '#ff6a00', navBackHref: '../guides', navBackLabel: 'All Guides', particleColors: ['#ff6a00'] };

contentType options: description → opens modal with HTML content | image → opens modal showing an image | link → navigates directly to link URL.

showTOC: true — add this to an article to enable the TOC button (works with h1–h6 and [data-toc] elements).

22 Article Card Badges

Badges are set in the article object in doc-data.js, not in HTML content.

{ title: 'My Article', subtitle: 'Description', icon: 'https://...icon.png', contentType: 'description', badge: { icon: '⭐', // Emoji OR image URL tooltip: 'Featured', // Hover text position: 'right' // 'right' = top-right corner // 'icon-tag' = overlaid on icon } }
23 TOC & Deep Links
Enabling the TOC

Add showTOC: true to your article object. The TOC button appears in the modal header and auto-generates from all h1–h6 tags in the description.

Custom TOC entries

Any element with data-toc="My label" will appear in the TOC even if it's not a heading.

Deep Links

Articles and sections are auto-linked via URL hash. Format: #article-slug opens the article. #article-slug--section-slug opens and scrolls to a specific section. These links are copyable via the copy icon in the TOC panel.
